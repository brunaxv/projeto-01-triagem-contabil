# Projeto 01 — Triagem administrativa contábil

Material de demonstração para triagem inicial de relatos fictícios. Todos os nomes, documentos, contatos, situações e valores deste projeto são inventados.

## Estrutura

- `apoio/`: relatos fictícios e regras de classificação e triagem.
- `docs/`: protocolo de uso e registro da execução.
- `saida/`: fichas geradas como rascunho.

## Uso e limites

Use somente dados fictícios. A triagem organiza informações e sugere encaminhamento; não presta orientação contábil, tributária ou jurídica, não confirma prazos e não agenda por conta própria. Um associado ou sócio deve revisar a ficha antes de qualquer encaminhamento ou resposta definitiva.
